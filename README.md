## 📌 Folder Overview

### 📗 Excel
Data cleaning and analysis using Excel functions (VLOOKUP, XLOOKUP, IF, COUNTIFS, SUMIFS), pivot tables, charts, and dashboards.

### 🐬 MySQL
SQL practice covering:
- `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`
- Joins (INNER, LEFT, RIGHT)
- Subqueries & CTEs
- Window functions
- Aggregate functions

### 📊 Power BI / Power Query
Importing, cleaning, and transforming data with Power Query, plus building interactive reports and DAX measures.

### 📈 Tableau
Building charts, calculated fields, and dashboards to present insights clearly.

## 🚀 How to Use This Repository

1. Clone the repository
   ```bash
   git clone https://github.com/Abhay07-tx/T389.git
   ```
2. Open the folder for the tool you want to explore.
3. Open the files with the matching software:
   - `.xlsx` → Microsoft Excel
   - `.sql` → MySQL Workbench
   - `.pbix` → Power BI Desktop
   - `.twb` / `.twbx` → Tableau Desktop / Public
